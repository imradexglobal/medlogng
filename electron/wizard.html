MediLog NG Host

This PC will serve the EMR to the whole building and keep handoffs safe during internet outages.

1 Import the key file

Select the Firebase service-account JSON file (the one that looks like new-project-service-account.json).

2 Enable secure microphone access (recommended)

Browser microphone access on LAN computers requires HTTPS. The existing HTTP address will remain available. Select a PFX certificate issued by a CA trusted on this Host and the client PCs; its names must cover the address clients will use. Ask IT to reserve the Host IP or provide a stable DNS name covered by the certificate. If a DHCP address changes and is not covered, secure recording stays unavailable until a matching certificate is imported. Deploy only the CA root certificate to client PCs; never copy the PFX there.

3 Open the firewall

Windows will ask for permission once — click Yes. This lets other PCs in the building reach this one. The rule applies to Domain and Private networks only; it never opens a Public network.

4 Finish

On every other PC: open Chrome, go to the LAN address, sign in with that user's own MediLog account, and bookmark it. No login secret needs copying. For microphone access, IT must trust the certificate issuer on those PCs.
